# 🧠 Salud Mental

## 📌 Descripción
Salud Mental es una página web desarrollada con el propósito de brindar información sobre la importancia del bienestar emocional y psicológico, así como promover el cuidado de la salud mental.

## 🎯 Objetivo
Crear un espacio informativo donde los usuarios puedan conocer más sobre la salud mental, sus cuidados y la importancia de mantener un bienestar emocional.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap 5

## 📁 Contenido del proyecto
- `index.html`: Página principal.
- `css/`: Archivos de estilos.
- `img/`: Imágenes utilizadas en la página.
- `js/`: Archivos JavaScript.
- `php/`: Archivos relacionados con la conexión y consultas a la base de datos.

## 🚀 Instalación y uso
1. Descargar o clonar el repositorio.
2. Colocar los archivos en la carpeta `htdocs` de XAMPP (si se utilizan funciones PHP).
3. Iniciar Apache y MySQL.
4. Configurar la conexión a la base de datos.
5. Abrir el proyecto desde el navegador utilizando localhost.

## 📚 Propósito
Proyecto escolar realizado para practicar el desarrollo web, el diseño de interfaces y el manejo de bases de datos.
